# Citing EPIOT

If you use EPIOT in academic work, please cite:

> Ravanbach, B., Turhan, E., Wulff, N., Orfanoudakis, S., Vergara, P. P., Vahidinasab, V., Dias, L.,
> & Mendes, G. (2024). *A dynamic prediction tool for vehicle-to-grid operation and planning.* In
> *2024 IEEE 22nd Mediterranean Electrotechnical Conference (MELECON)*.

```bibtex
@inproceedings{ravanbach2024epiot,
  title     = {A dynamic prediction tool for vehicle-to-grid operation and planning},
  author    = {Ravanbach, Babak and Turhan, Elif and Wulff, Niklas and Orfanoudakis, Stavros and
               Vergara, Pedro P. and Vahidinasab, Vahid and Dias, Luis and Mendes, Gon{\c{c}}alo},
  booktitle = {2024 IEEE 22nd Mediterranean Electrotechnical Conference (MELECON)},
  year      = {2024}
}
```
