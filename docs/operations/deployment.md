# Deployment

For anything beyond local development, run EPIOT under a WSGI server behind a reverse proxy.

```{mermaid}
flowchart TB
    U([Users]) -->|HTTPS| RP[Reverse proxy<br/>nginx / Apache]
    RP -->|HTTP 127.0.0.1:5000| GU[gunicorn<br/>4 workers]
    GU --> APP[Flask app<br/>app:app]
    APP --> DB[(instance/default.sqlite)]
    CRON([cron]) --> UPD[update_database.py] --> DB
```

## 1. Switch off debug mode

`app.py` has a module-level flag:

```python
DEBUG = True
```

Set it to `False` for production. This disables the Werkzeug debugger and reloader and wraps the app
in `ProxyFix(x_for=1, x_proto=1, x_host=1, x_prefix=1)`, so URLs generated by Flask (for example the
icon URLs from `/marker_icon`) use the scheme, host and path prefix forwarded by the proxy.

:::{danger}
Never expose the app with `DEBUG = True`. The Werkzeug debugger allows arbitrary code execution from
the browser.
:::

## 2. Run under gunicorn

`scripts/run_file.sh` shows the production command:

```bash
gunicorn --limit-request-line 18190 -w 4 -b 127.0.0.1:5000 app:app
```

| Option | Why |
|---|---|
| `--limit-request-line 18190` | `/stations/aggregate_load` and `/kpi/user` carry all charger IDs of an area in the query string; large areas exceed gunicorn's default 4094-byte request line. |
| `-w 4` | Four worker processes. KPI and `ocost` requests can take several seconds; more workers keep the app responsive. |
| `-b 127.0.0.1:5000` | Listen on localhost only; the proxy terminates public traffic. |

Set `SPATIALITE_LIBRARY_PATH` in the service environment if the library is not on the default search
path.

## 3. Reverse proxy

A minimal nginx site:

```nginx
server {
    listen 443 ssl;
    server_name epiot.example.org;

    # ssl_certificate / ssl_certificate_key …

    large_client_header_buffers 4 32k;   # long query strings
    proxy_read_timeout 300s;             # KPI and ocost requests can be slow

    location / {
        proxy_pass         http://127.0.0.1:5000;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_set_header   X-Forwarded-Host  $host;
    }
}
```

To serve EPIOT under a sub-path (for example `/epiot`), also set
`proxy_set_header X-Forwarded-Prefix /epiot;`.

## 4. Run as a service

A systemd unit keeps gunicorn running and restarts it on failure:

```ini
[Unit]
Description=EPIOT web application
After=network.target

[Service]
WorkingDirectory=/opt/epiot
Environment=SPATIALITE_LIBRARY_PATH=mod_spatialite.so
ExecStart=/opt/epiot/.venv/bin/gunicorn --limit-request-line 18190 -w 4 -b 127.0.0.1:5000 app:app
Restart=on-failure
User=epiot

[Install]
WantedBy=multi-user.target
```

## Production checklist

- [ ] `DEBUG = False` in `app.py`
- [ ] gunicorn with `--limit-request-line` and enough workers
- [ ] Reverse proxy with TLS, forwarded headers and a generous read timeout
- [ ] `SPATIALITE_LIBRARY_PATH` set for the service user
- [ ] `ELECTRICITYMAPS_API_TOKEN` set for the update job
- [ ] Daily `update_database.py` scheduled and logging to `logs/`
- [ ] Database file backed up (it is a single file: `instance/default.sqlite`)
- [ ] Outbound HTTPS allowed to the services in {doc}`../architecture/external-services`
